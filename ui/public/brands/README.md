# Brand marks

Square vector logos used by the provider picker. They are brand assets, not PDFScope artwork:

- `deepseek.svg`, `anthropic.svg`, `gemini.svg`, `xiaomi.svg`, `moonshot.svg`, `openrouter.svg`,
  `ollama.svg` — [Simple Icons](https://simpleicons.org), CC0, fetched through
  `https://cdn.simpleicons.org/<slug>/<colour>`.
- `openai.svg` — OpenAI 2025 blossom symbol from
  [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg),
  public domain as a simple geometric logo; the trademark remains OpenAI's.

Trademarks belong to their owners; these files are used only to identify the configured provider.
